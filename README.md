# Fan Arena — Football Fan Competition Preview

Interactive, mobile-first frontend prototype for a football fan competition platform connected to a YouTube creator community.

## Stack

- Next.js 16 (App Router)
- TypeScript
- Tailwind CSS 4
- Local mock data + EN/AR i18n (RTL)

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

```bash
npm run lint
npm run typecheck
npm run build
npm run start
```

## Deploy (Vercel)

This is a standard Next.js App Router project with no required environment variables and no backend.

Connect the GitHub repository in Vercel and deploy with the default Next.js settings.

## Notes

This is a product preview only. There is no backend, real auth, live YouTube integration, payments, or admin CRUD. Demo interactions are local-only.
